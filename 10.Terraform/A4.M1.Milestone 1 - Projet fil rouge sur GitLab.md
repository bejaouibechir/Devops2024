# Milestone 1 — Projet fil rouge sur GitLab

> **Ateliers couverts :** A0 · A1 · A2 · A3 · A4

---

## Objectif du milestone

À la fin de ce milestone, le projet fil rouge existe sur GitLab et provisionne un **Resource Group Azure** via Terraform. Les variables sont typées, validées et le projet est structuré pour évoluer sur les milestones suivants.

---

## Infrastructure déployée

```
Azure
└── Resource Group  (nom dynamique selon environnement + projet)
```

Pas encore de réseau ni de VM — le Resource Group est la fondation sur laquelle tout se construira.

---

## Structure du projet à atteindre

```
terraform-fil-rouge/
├── versions.tf          # contraintes de version Terraform + providers
├── main.tf              # appel des ressources (Resource Group)
├── variables.tf         # déclaration des variables
├── terraform.tfvars     # valeurs par défaut (dev)
├── outputs.tf           # outputs exposés

```

---

## Providers utilisés

| Provider | Usage |
|---|---|
| `hashicorp/azurerm` | Créer le Resource Group Azure |
| `gitlabhq/gitlab` | Gérer le dépôt GitLab via Terraform |

```hcl
# versions.tf
terraform {
  required_version = ">= 1.6"

  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "~> 3.110"
    }
    gitlab = {
      source  = "gitlabhq/gitlab"
      version = "~> 17.0"
    }
  }
}
```

## Variables à définir

| Variable | Type | Validation | Exemple |
|---|---|---|---|
| `project` | `string` | 3–20 chars, lowercase | `"fil-rouge"` |
| `environment` | `string` | `dev`, `staging`, `prod` | `"dev"` |
| `location` | `string` | régions Azure autorisées | `"francecentral"` |
| `owner` | `string` | non vide | `"bechir"` |

Exemple de validation sur `environment` :

```hcl
variable "environment" {
  type = string
  validation {
    condition     = contains(["dev", "staging", "prod"], var.environment)
    error_message = "environment doit être dev, staging ou prod."
  }
}
```

---

## Ressource cible

```hcl
resource "azurerm_resource_group" "main" {
  name     = "rg-${var.project}-${var.environment}"
  location = var.location

  tags = {
    project     = var.project
    environment = var.environment
    owner       = var.owner
    managed_by  = "terraform"
  }
}
```

## Critères de validation du milestone

- [ ] Le dépôt GitLab `terraform-fil-rouge` est créé et versionné
- [ ] `terraform init` s'exécute sans erreur
- [ ] `terraform validate` passe
- [ ] `terraform plan` affiche la création du Resource Group
- [ ] `terraform apply` crée le Resource Group sur Azure
- [ ] Une variable invalide (`environment = "recette"`) déclenche une erreur de validation
- [ ] Le `.gitignore` exclut les fichiers sensibles

---

## Points de vigilance

- Le token GitLab doit être dans `GITLAB_TOKEN` (variable d'environnement), jamais dans le code.
- Les credentials Azure doivent être dans les variables d'environnement `ARM_*` ou via `az login`.
- Ne pas committer `terraform.tfstate` ni `*.tfvars` contenant des secrets.
