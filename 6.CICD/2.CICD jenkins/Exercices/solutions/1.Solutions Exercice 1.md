# Premiere version 

Utilise un paramètre comme input:

```groovy

// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
  // Exécute le pipeline sur un agent Jenkins disponible et éligible.
  agent any
  // Déclare les valeurs saisies avant le lancement du build, accessibles via params.
  parameters {
    string(name: 'NOM', defaultValue: 'Jean', description: 'Quel est votre nom ?')
  }
  // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
  stages {
    // Ouvre la phase « Salutation », visible séparément dans le suivi du build.
    stage('Salutation') {
      // Regroupe les actions exécutées dans cette phase.
      steps {
        // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
        echo "Bonjour ${params.NOM}"
      }
    }
  }
}

```

# Deuxième version 

Reçoit le nom de l'utilisateur depuis un fichier

```groovy

// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any

    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
       
        // Ouvre la phase « Lecture fichier /tmp/input », visible séparément dans le suivi du build.
        stage('Lecture fichier /tmp/input') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Lecture du fichier contenant un nom
                    def contenuFichier = sh(script: 'cat /tmp/input', returnStdout: true).trim()
                    // Met à jour une variable d'environnement réutilisée par les étapes suivantes du pipeline.
                    env.NOM_FICHIER = contenuFichier
                }
            }
        }

        // Ouvre la phase « Affichage des noms », visible séparément dans le suivi du build.
        stage('Affichage des noms') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                echo "Nom saisi via Jenkins : ${env.NOM_UTILISATEUR}"
                // Suspend le pipeline pour recueillir la réponse humaine, puis la stocke si une variable est déclarée.
                echo "Nom lu depuis le fichier /tmp/input : ${env.NOM_FICHIER}"
            }
        }
    }
}

```

# Deuxième version améliorée 

Qui prend en considération la gestion des erreurs

```groovy

// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any

    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
       
        // Ouvre la phase « Lecture fichier /tmp/input », visible séparément dans le suivi du build.
        stage('Lecture fichier /tmp/input') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                 // Exécute les opérations dont les exceptions pourront être traitées dans catch.
                 try{
                    // Lecture du fichier contenant un nom
                    def contenuFichier = sh(script: 'cat /tmp/input', returnStdout: true).trim()
                    // Met à jour une variable d'environnement réutilisée par les étapes suivantes du pipeline.
                    env.NOM_FICHIER = contenuFichier

                 } 
                 catch(Exception e)
                 {
                     // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                     echo "Une erreur est survenue"
                     echo ${e.getMessage()}
                 }
                  
                }
            }
        }

        // Ouvre la phase « Affichage des noms », visible séparément dans le suivi du build.
        stage('Affichage des noms') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                echo "Nom saisi via Jenkins : ${env.NOM_UTILISATEUR}"
                // Suspend le pipeline pour recueillir la réponse humaine, puis la stocke si une variable est déclarée.
                echo "Nom lu depuis le fichier /tmp/input : ${env.NOM_FICHIER}"
            }
        }
    }
}

```
