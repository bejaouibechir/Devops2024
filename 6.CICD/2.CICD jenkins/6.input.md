### **`input`** et conditions pour exécuter des étapes différentes en fonction de la réponse :

### Explication :

- **`input`** : Demande à l'utilisateur s'il approuve le build, avec deux choix (`Yes` et `No`).
- **`userInput`** : Le résultat de l'`input` est capturé dans la variable `userInput`. Si la réponse est **`Yes`**, le pipeline poursuit avec le stage "Yes", sinon il continue avec le stage "No".
- **`when`** : Les blocs `when` sont utilisés pour conditionner l'exécution des stages "Yes" et "No" en fonction de la réponse de l'utilisateur stockée dans `currentBuild.description`.

```groovy
// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any
    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
        // Ouvre la phase « Build », visible séparément dans le suivi du build.
        stage('Build') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                    echo 'Building the project...'
                }
            }
        }
        // Ouvre la phase « Approval », visible séparément dans le suivi du build.
        stage('Approval') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Suspend le pipeline pour recueillir la réponse humaine, puis la stocke si une variable est déclarée.
                    def userInput = input message: 'Do you approve the build?', parameters: [
                        choice(name: 'Approval', choices: ['Yes', 'No'], description: 'Approve or Reject the Build')
                    ]
                    // Stocker la réponse de l'utilisateur dans une variable
                    if (userInput == 'Yes') {
                        // Stocke une description du build, réutilisée ici par les conditions.
                        currentBuild.description = 'Approved'
                    } else {
                        currentBuild.description = 'Rejected'
                    }
                }
            }
        }
        // Ouvre la phase « Yes », visible séparément dans le suivi du build.
        stage('Yes') {
            // Évalue la condition avant de décider si ce stage doit s'exécuter.
            when {
                // Le booléen retourné décide si la condition du stage est satisfaite.
                expression { return currentBuild.description == 'Approved' }
            }
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                    echo 'The build was approved. Proceeding with Yes stage.'
                }
            }
        }
        // Ouvre la phase « No », visible séparément dans le suivi du build.
        stage('No') {
            // Évalue la condition avant de décider si ce stage doit s'exécuter.
            when {
                // Le booléen retourné décide si la condition du stage est satisfaite.
                expression { return currentBuild.description == 'Rejected' }
            }
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                    echo 'The build was rejected. Proceeding with No stage.'
                }
            }
        }
    }
}
```
