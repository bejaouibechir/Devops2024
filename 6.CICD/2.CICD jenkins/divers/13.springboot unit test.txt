# Configuration des tests unitaires pour un projet springboot

### 1. **Configurer le projet Spring Boot pour les tests unitaires**

Le projet **Spring Boot** doit ^^ete configuré pour exécuter des tests unitaires. Spring Boot utilise par défaut **JUnit** ou **JUnit5** pour les tests unitaires. Vérifie que tes tests sont correctement configurés.

#### Exemple de dépendances pour Maven (`pom.xml`):

```xml
<!-- Déclare les bibliothèques utilisées par le projet. -->
<dependencies>
    <!-- Dépendances pour les tests unitaires -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <!-- Limite cette dépendance à la compilation et à l'exécution des tests. -->
        <scope>test</scope>
    </dependency>
</dependencies>
```

#### Exemple de dépendances pour Gradle (`build.gradle`):

```gradle
dependencies {
    // Ajoute la bibliothèque au périmètre des tests Gradle.
    testImplementation 'org.springframework.boot:spring-boot-starter-test'
}
```

### 2. **Configurer le fichier `Jenkinsfile`**

L'étape suivante consiste à intégrer l'exécution des tests dans ton pipeline Jenkins. Tu peux utiliser **Maven** ou **Gradle** pour exécuter les tests unitaires.

#### Exemple de `Jenkinsfile` pour Maven :

```groovy
// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any

    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
        // Ouvre la phase « Checkout », visible séparément dans le suivi du build.
        stage('Checkout') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                git 'https://gitlab.com/vadimaentreprise/remoteproject.git'
            }
        }

        // Ouvre la phase « Build », visible séparément dans le suivi du build.
        stage('Build') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                sh 'mvn clean install -DskipTests=false'  // Exécute le build et les tests
            }
        }

        // Ouvre la phase « Unit Tests », visible séparément dans le suivi du build.
        stage('Unit Tests') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Exécuter les tests unitaires avec Maven
                sh 'mvn test'
            }
        }

        // Ouvre la phase « Test Reports », visible séparément dans le suivi du build.
        stage('Test Reports') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                junit '**/target/test-classes/*.xml' // Rapports de tests JUnit (examine le dossier de test pour les rapports XML)
            }
        }

        // Ouvre la phase « SonarQube Analysis », visible séparément dans le suivi du build.
        stage('SonarQube Analysis') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Analyse SonarQube après les tests
                    withSonarQubeEnv('SonarQube') {
                        // Envoie l'analyse du projet à SonarQube avec la configuration disponible.
                        sh 'mvn sonar:sonar'
                    }
                }
            }
        }

        // Ouvre la phase « Quality Gate », visible séparément dans le suivi du build.
        stage('Quality Gate') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Attendre le résultat de l'analyse SonarQube (Quality Gate)
                    def qualityGate = waitForQualityGate()
                    // Choisit la branche à exécuter selon cette condition Groovy.
                    if (qualityGate.status != 'OK') {
                        // Lève une erreur pour interrompre le traitement et signaler son échec.
                        error "Quality Gate failed: ${qualityGate.status}"
                    }
                }
            }
        }
    }
}
```
