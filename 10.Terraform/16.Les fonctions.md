# Atelier 5 : Découverte des Fonctions Terraform

## 1. Introduction

## À quoi servent les fonctions Terraform ?

Les **fonctions Terraform** servent à transformer, combiner, nettoyer ou calculer des valeurs dans le code Terraform.

Exemples simples :

```hcl
upper("dev")
```

Résultat :

```text
DEV
```

```hcl
join("-", ["app", "dev", "01"])
```

Résultat :

```text
app-dev-01
```

```hcl
length(["api", "web", "worker"])
```

Résultat :

```text
3
```

Terraform fournit des fonctions intégrées utilisables dans les expressions, avec une syntaxe du type **nom_fonction(argument1, argument2)**. Ces fonctions permettent de transformer et combiner des valeurs dans la configuration. ([HashiCorp Developer](https://developer.hashicorp.com/terraform/language/functions?utm_source=chatgpt.com "Functions - Configuration Language | Terraform"))

## Objectifs de l’atelier

À la fin de cet atelier, vous saurez utiliser :

**fonctions string** : **upper**, **lower**, **trimspace**, **replace**, **format**  
**fonctions numeric** : **max**, **min**, **ceil**, **floor**  
**fonctions bool et conditionnelles** : **coalesce**, **try**, **can**  
**fonctions collection** : **length**, **keys**, **values**, **element**, **join**, **split**, **contains**  
**fonctions fichier** : **file**, **templatefile**  
**fonctions de conversion** : **tolist**, **toset**, **tomap**, **tostring**, **tonumber**

On va combiner ces fonctions avec :

**variables**,

## 3.3 Créer le fichier main.tf

Créer le fichier **main.tf** :

```hcl
# Déclare le provider Local.
terraform {
  required_providers {
    local = {
      source  = "hashicorp/local"
      version = "~> 2.5"
    }
  }
}

# Le provider Local ne nécessite aucune configuration.
provider "local" {}

# locals centralise les valeurs calculées avec des fonctions.
locals {
  # trimspace supprime les espaces au début et à la fin.
  app_name_clean = trimspace(var.app_name)

  # lower transforme en minuscules.
  app_name_lower = lower(local.app_name_clean)

  # replace remplace les espaces par des tirets.
  app_slug = replace(local.app_name_lower, " ", "-")

  # upper transforme en majuscules.
  environment_upper = upper(var.environment)

  # max garantit un minimum de 2 instances.
  safe_instances = max(var.requested_instances, 2)

  # coalesce retourne la première valeur non nulle et non vide.
  effective_contact = coalesce(var.contact_email, "admin@example.com")

  # format construit une chaîne avec des emplacements.
  report_title = format("Rapport %s pour %s", local.app_slug, local.environment_upper)
}

# Génère un rapport avec les valeurs calculées.
resource "local_file" "base_functions_report" {
  filename = "base-functions-report.txt"

  content = <<EOT
${local.report_title}

Nom brut : ${var.app_name}
Nom nettoyé : ${local.app_name_clean}
Slug : ${local.app_slug}
Environnement : ${local.environment_upper}
Instances demandées : ${var.requested_instances}
Instances retenues : ${local.safe_instances}
Contact effectif : ${local.effective_contact}
EOT
}
```

## 4.4 Créer le fichier main.tf

Créer le fichier **main.tf** :

```hcl
# Déclare le provider Local.
terraform {
  required_providers {
    local = {
      source  = "hashicorp/local"
      version = "~> 2.5"
    }
  }
}

provider "local" {}

locals {
  # length compte le nombre d'éléments.
  service_count = length(var.services)

  # element récupère un élément par index.
  first_service = element(var.services, 0)

  # keys retourne les clés d'une map.
  tag_keys = keys(var.tags)

  # values retourne les valeurs d'une map.
  tag_values = values(var.tags)

  # contains vérifie si une liste contient une valeur.
  api_enabled = contains(var.enabled_services, "api")

  # toset convertit une liste en set pour for_each.
  enabled_services_set = toset(var.enabled_services)

  # tomap force une valeur à être une map.
  normalized_tags = tomap(var.tags)

  # join transforme une liste en texte.
  services_as_text = join(", ", var.services)
}

# Crée un rapport global sur les collections.
resource "local_file" "collection_report" {
  filename = "collection-report.txt"

  content = <<EOT
Rapport collections

Nombre de services : ${local.service_count}
Premier service : ${local.first_service}
Services : ${local.services_as_text}

Clés des tags : ${join(", ", local.tag_keys)}
Valeurs des tags : ${join(", ", local.tag_values)}

API activée : ${local.api_enabled}
EOT
}

# Crée un fichier par service activé.
resource "local_file" "enabled_service_file" {
  for_each = local.enabled_services_set

  filename = "service-${each.key}.txt"

  content = <<EOT
Service activé

Nom : ${each.key}
Présent dans enabled_services : ${contains(var.enabled_services, each.key)}
EOT
}
```

```hcl
# Déclare le provider Local.
terraform {
  required_providers {
    local = {
      source  = "hashicorp/local"
      version = "~> 2.5"
    }
  }
}

provider "local" {}

locals {
  # file lit un fichier qui existe déjà dans le dossier.
  intro_content = file("${path.module}/intro.txt")

  # templatefile rend un template avec des variables.
  rendered_config = templatefile("${path.module}/templates/app.conf.tftpl", {
    app_name      = var.app_name
    environment   = var.environment
    service_count = length(var.services)
    services      = join(",", var.services)
    service_list  = var.services
    debug_enabled = var.debug_enabled
  })
}

# Fichier généré à partir de file.
resource "local_file" "intro_copy" {
  filename = "intro-copy.txt"
  content  = local.intro_content
}

# Fichier généré à partir de templatefile.
resource "local_file" "app_config" {
  filename = "app.conf"
  content  = local.rendered_config
}
```

## 6.4 Créer le fichier main.tf

Créer le fichier **main.tf** :

```hcl
# Déclare le provider Local.
terraform {
  required_providers {
    local = {
      source  = "hashicorp/local"
      version = "~> 2.5"
    }
  }
}

provider "local" {}

locals {
  # Nettoie et normalise le nom du projet.
  project_slug = replace(lower(trimspace(var.project_name)), " ", "-")

  # Met l'environnement en majuscules.
  env_upper = upper(var.environment)

  # Définit un contact par défaut si contact_email est vide.
  effective_contact = coalesce(var.contact_email, "admin@example.com")

  # compact supprime les chaînes vides.
  services_without_empty = compact(var.raw_services)

  # distinct supprime les doublons.
  services_unique = distinct(local.services_without_empty)

  # sort trie la liste.
  services_sorted = sort(local.services_unique)

  # join transforme la liste en texte.
  services_text = join(", ", local.services_sorted)

  # split transforme une chaîne CSV en liste.
  ports_list = split(",", var.ports_csv)

  # format construit un identifiant lisible.
  identifier = format("%s-%s", local.project_slug, lower(var.environment))
}

resource "local_file" "advanced_functions_report" {
  filename = "${local.identifier}.txt"

  content = <<EOT
Rapport fonctions avancées

Projet brut : ${var.project_name}
Projet normalisé : ${local.project_slug}
Environnement : ${local.env_upper}
Identifiant : ${local.identifier}
Contact : ${local.effective_contact}

Services bruts :
${join(", ", var.raw_services)}

Services nettoyés, uniques et triés :
${local.services_text}

Ports CSV :
${var.ports_csv}

Ports transformés en liste :
${join(" | ", local.ports_list)}
EOT
}
```

## 6.11 Attention

Une chaîne vide n’est pas toujours équivalente à **null**.

# 7. Étape 5 : Bonnes pratiques et pièges courants

## 7.1 Tableau récapitulatif des fonctions utiles

| Catégorie                 | Fonctions                                                    | Usage                              |
| ------------------------- | ------------------------------------------------------------ | ---------------------------------- |
| **String**                | **upper**, **lower**, **trimspace**, **replace**, **format** | Nettoyer et construire du texte    |
| **Numeric**               | **min**, **max**, **ceil**, **floor**                        | Encadrer ou ajuster des nombres    |
| **Collection**            | **length**, **keys**, **values**, **contains**, **element**  | Lire et inspecter listes et maps   |
| **Transformation**        | **join**, **split**, **compact**, **distinct**, **sort**     | Transformer des listes et chaînes  |
| **File**                  | **file**, **templatefile**                                   | Lire ou générer depuis un template |
| **Conversion**            | **tolist**, **toset**, **tomap**, **tostring**, **tonumber** | Convertir explicitement des types  |
| **Sécurité d’expression** | **try**, **can**, **coalesce**                               | Gérer des valeurs optionnelles     |

---

## 7.2 Bonnes pratiques

| Situation                | Bonne pratique                               |
| ------------------------ | -------------------------------------------- |
| Expression courte        | Fonction directement dans l’argument         |
| Expression longue        | Calcul dans **locals**                       |
| Template long            | Utiliser **templatefile**                    |
| Liste à afficher         | Utiliser **join**                            |
| CSV à transformer        | Utiliser **split**                           |
| Valeur optionnelle       | Utiliser **coalesce** ou ternaire            |
| Nettoyage de liste       | Utiliser **compact**, **distinct**, **sort** |
| Vérification avant accès | Utiliser **try** ou **can**                  |

---

## 7.3 Pièges fréquents

| Piège                                                                | Explication                                           |
| -------------------------------------------------------------------- | ----------------------------------------------------- |
| Lire avec **file** un fichier créé pendant **apply**                 | Impossible, le fichier doit déjà exister au début     |
| Mettre trop de fonctions dans une seule ligne                        | Code difficile à lire                                 |
| Confondre **join** et **split**                                      | **join** liste vers texte, **split** texte vers liste |
| Utiliser **element** sans comprendre l’index                         | Risque de mauvaise valeur                             |
| Utiliser **toset** quand l’ordre compte                              | Un set n’a pas d’ordre garanti                        |
| Supposer que **templatefile** peut appeler récursivement un template | Non, les appels récursifs ne sont pas permis          |
