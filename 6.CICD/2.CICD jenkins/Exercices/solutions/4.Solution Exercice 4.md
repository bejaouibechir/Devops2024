# Exemple de pipeline 


```groovy

// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
  // Exécute le pipeline sur un agent Jenkins disponible et éligible.
  agent any
  // Règle le comportement d'exécution et de conservation pour cette portée.
  options {
    // Limite la durée de la portée ; cette limite n'est pas une attente.
    timeout(time: 2, unit: 'MINUTES')
    // Réexécute la portée en cas d'échec, jusqu'au nombre maximal de tentatives indiqué.
    retry(2)
  }
  // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
  stages {
    // Ouvre la phase « Attente », visible séparément dans le suivi du build.
    stage('Attente') {
      // Regroupe les actions exécutées dans cette phase.
      steps {
        // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
        echo 'Test du pipeline'
      }
    }
  }
}
```
