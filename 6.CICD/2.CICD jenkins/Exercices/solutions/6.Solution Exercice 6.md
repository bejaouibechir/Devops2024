## Exemple de pipeline


```groovy
// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any

    // Déclare les variables d'environnement disponibles dans cette portée du pipeline.
    environment{
        IP_PUBLIQUE_VM = '' //A recuperer de AWS
        UTILISATEUR_SSH= '' //Nom de l'utilisateur exemple jenkins
    }

    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
        // Ouvre la phase « Exécution SSH distante », visible séparément dans le suivi du build.
        stage('Exécution SSH distante') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Exécute la commande indiquée sur la machine distante via SSH Pipeline Steps.
                sshCommand remote: [
                    host: 'IP_PUBLIQUE_VM',           // À remplacer par l'IP réelle
                    user: 'UTILISATEUR_SSH',          // Exemple : jenkins
                    identityFile: '/chemin/vers/id_rsa', // Clé privée du Jenkins agent
                    // Cet exemple accepte toute clé d'hôte ; il ne vérifie donc pas l'identité du serveur.
                    allowAnyHosts: true
                ],
                command: 'uptime' // Ou tout autre script à exécuter à distance
            }
        }
    }
}
```
