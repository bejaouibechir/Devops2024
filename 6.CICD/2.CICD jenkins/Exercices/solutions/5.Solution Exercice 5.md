## Exemple de pipeline

```groovy
// Définit le pipeline déclaratif piloté par Jenkins.
pipeline {
    // Exécute le pipeline sur un agent Jenkins disponible et éligible.
    agent any

    // Déclare les variables d'environnement disponibles dans cette portée du pipeline.
    environment {
        // Variable globale qui sera redéfinie dynamiquement
        TARGET_ENV = ''
    }

    // Organise les phases du pipeline ; leur ordre est séquentiel hors branches parallèles.
    stages {
        // Ouvre la phase « Sélection de l\'environnement », visible séparément dans le suivi du build.
        stage('Sélection de l\'environnement') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Exécute les opérations dont les exceptions pourront être traitées dans catch.
                    try {
                        // Suspend le pipeline pour recueillir la réponse humaine, puis la stocke si une variable est déclarée.
                        def choix = input message: 'Choisissez l’environnement de déploiement :', parameters: [
                            choice(name: 'ENVIRONNEMENT', choices: ['dev', 'staging', 'prod'], description: 'Cible')
                        ]
                        // Met à jour une variable d'environnement réutilisée par les étapes suivantes du pipeline.
                        env.TARGET_ENV = choix
                        // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                        echo "✅ Environnement sélectionné : ${env.TARGET_ENV}"
                    // Traite l'exception levée dans try et choisit le résultat à conserver.
                    } catch (e) {
                        // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                        echo "❌ Action annulée par l’utilisateur : ${e.getMessage()}"
                        // Fixe explicitement le résultat du build dans Jenkins.
                        currentBuild.result = 'ABORTED'
                        // Lève une erreur pour interrompre le traitement et signaler son échec.
                        error("Fin du pipeline")
                    }
                }
            }
        }

        // Ouvre la phase « Initialisation des variables », visible séparément dans le suivi du build.
        stage('Initialisation des variables') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Sélectionne la configuration correspondant à la valeur choisie.
                    switch (env.TARGET_ENV) {
                        case 'dev':
                            env.API_URL = 'https://dev.api.local'
                            // Met à jour une variable d'environnement réutilisée par les étapes suivantes du pipeline.
                            env.DB_NAME = 'dev_db'
                            break
                        case 'staging':
                            env.API_URL = 'https://staging.api.local'
                            env.DB_NAME = 'staging_db'
                            break
                        case 'prod':
                            env.API_URL = 'https://api.local'
                            env.DB_NAME = 'prod_db'
                            break
                        default:
                            // Lève une erreur pour interrompre le traitement et signaler son échec.
                            error("Environnement non reconnu : ${env.TARGET_ENV}")
                    }
                    // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                    echo "🔧 Variables configurées :"
                    echo "- API_URL = ${env.API_URL}"
                    echo "- DB_NAME = ${env.DB_NAME}"
                }
            }
        }

        // Ouvre la phase « Déploiement spécifique », visible séparément dans le suivi du build.
        stage('Déploiement spécifique') {
            // Regroupe les actions exécutées dans cette phase.
            steps {
                // Permet la logique Groovy : variables locales, conditions et boucles.
                script {
                    // Choisit la branche à exécuter selon cette condition Groovy.
                    if (env.TARGET_ENV == 'dev') {
                        // Écrit un message dans la console Jenkins ; ce message seul ne réalise pas l'opération annoncée.
                        echo "🚀 Déploiement DEV en cours..."
                        // Commandes spécifiques à DEV
                    } else if (env.TARGET_ENV == 'staging') {
                        echo "🚀 Déploiement STAGING en cours..."
                        // Commandes spécifiques à STAGING
                    } else if (env.TARGET_ENV == 'prod') {
                        echo "🚀 Déploiement PROD en cours..."
                        // Commandes spécifiques à PROD
                    }
                }
            }
        }
    }
}
```
